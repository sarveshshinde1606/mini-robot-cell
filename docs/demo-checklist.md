# Demo recording checklist

Keep the recording around 2–3 minutes.

1. Start from the repository and run `docker compose up --build`.
2. Open `http://localhost:8080`.
3. Move all six React sliders and point out rad/degree values.
4. Press HOME.
5. Press E-STOP; show disabled sliders and backend rejection log; press RESET.
6. Click the Vue camera image; show source pixel, mm offset and +X latency compensation.
7. Stop the backend container; show the WebSocket indicator turn red; start it again; show reconnect.
8. Stop/deny camera access and show the synthetic fallback continues to work.
9. End on the running console and README's honest scope-cut list.
